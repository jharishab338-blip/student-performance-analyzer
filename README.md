# Student Performance Analyzer

A beginner-friendly Python project that collects student marks, validates input, and generates individual performance reports along with the overall class average.

## Features

- Accepts records for multiple students.
- Collects marks in Physics, Chemistry, and Mathematics.
- Validates marks to ensure they are between 0 and 100.
- Calculates total marks and average marks.
- Assigns grades based on student averages.
- Identifies each student's highest and lowest scoring subjects.
- Calculates the overall class average.
- Handles invalid marks input and an empty class.

## Technologies Used

- Python 3
- Dictionaries
- Lists
- Loops and conditional statements
- Functions
- Exception handling

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
python main.py
```

5. Enter the number of students, their names, and their subject marks.
